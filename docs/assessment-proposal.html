Migration proposal

A staged path from evidence closure to controlled Fabric pilot

Phase 01 / prove

Evidence and security closure

  • Resolve the unsupported security policy mapping.
  • Complete missing adapter evidence.
  • Approve source-to-target ownership and RLS assumptions.
Phase 02 / pilot

Dependency-spine rehearsal

  • Rehearse ingestion, storage, transformation, and orchestration.
  • Validate generated artifacts against official Fabric schemas.
  • Capture schema, row-count, SQL-result, and checksum evidence.
Phase 03 / scale

Wave expansion and governance

  • Promote approved workloads by migration wave.
  • Introduce live adapter/sandbox validation.
  • Require rollback, identity, audit, and parity sign-off.
